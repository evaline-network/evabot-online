# Голосовий модуль-плагін EvaBot Gemini Live — Специфікація та архітектура (UK)

## Загальний опис
**Голосовий модуль EvaBot Gemini Live** — це ізольований, підключуваний (plug-and-play) модуль голосової взаємодії на базі **Google Gemini Multimodal Live API** (`BidiGenerateContent` через WebSockets). Модуль забезпечує природний, живий діалог людини та ШІ з ультранизькою затримкою, підтримкою миттєвого перебивання мови (barge-in) та двома ключовими характерами:
- **Єва (Eva)**: Головний FrontEnd & UX Архітектор, виразний, теплий, чіткий жіночий голос (`Aoede`).
- **Адам (Adam)**: Головний BackEnd & Cloud Архітектор, глибокий, авторитетний, аналітичний чоловічий голос (`Fenrir`).

---

## Ключові можливості

### 1. Ізольована плагінна архітектура
- Відокремлений у самостійні директорії `src/plugins/voice/` (бекенд-контролер і конфігурації) та `src/web/voice/` (клієнтський аудіо-рушій Web Audio API та інтерфейс).
- Легко вмикається та вимикається на льоту (`POST /api/voice/toggle` або кнопка в UI `[ PLUGIN: ON/OFF ]`).
- При вимкненому стані не створює жодного навантаження на текстовий термінал чи consilium.

### 2. Два персонажі та динамічне перемикання голосу
- **Єва (♀ / Aoede)**: Спеціалізація на фронтенді, дизайні інтерфейсів, клієнтській архітектурі та ергономіці взаємодії.
- **Адам (♂ / Fenrir)**: Спеціалізація на бекенді, розподілених системах, PostgreSQL, кластерах та хмарній безпеці.
- **Голосове перемикання**: Якщо користувач звертається *"Єва / Eva"* або *"Адам / Adam"*, система розпізнає тригер та миттєво перемикає голос і роль.

### 3. Нативна багатомовність
- Підтримка **5 мов** з бездоганною людською вимовою:
  - Українська (UK)
  - Англійська (EN)
  - Польська (PL)
  - Румунська (RO)
  - Російська (RU)
- Модель автоматично відповідає тією мовою, якою користувач звернувся до неї.

### 4. Аудіо-пайплайн наднизької затримки
- **Захоплення мікрофона**: 16 000 Гц, 16 біт PCM little-endian через Web Audio API і передача Base64-чанків у сокет.
- **Відтворення мови**: 24 000 Гц PCM через буферизовану чергу Web Audio API з компенсацією джитера.
- **Миттєвий Barge-In (перебивання)**: відтворення негайно глушиться, коли користувач починає говорити.
- **Кібер-осцилограф**: Canvas-візуалізатор спектра та амплітуди в реальному часі.
