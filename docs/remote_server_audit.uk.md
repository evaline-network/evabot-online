## 1. Загальний огляд

Проведено комплексний аудит високопродуктивного хмарного сервера **`evabot-agent-vm`** за допомогою `gcloud compute ssh`. Усі ключові підсистеми, включно з процесором, 32 ГБ оперативної пам'яті DDR5, швидким NVMe-накопичувачем, фоновими службами systemd, Python-шлюзом Antigravity (порт 9090) та Web IDE Code-Server (порт 8080), функціонують у штатному режимі з оптимальними показниками.

## 4. Верифікація API шлюзу Antigravity (порт 9090)

Виконано перевірочний HTTP-запит до ендпоінта `http://localhost:9090/status`:

```bash
curl -s http://localhost:9090/status
```

**Відповідь JSON (HTTP 200 OK):**
```json
{
  "status": "online",
  "server": "evabot-agent-vm",
  "tailscale_ip": "100.66.98.4",
  "antigravity_cli": true,
  "antigravity_ide": true
}
```

Підтвердження: Підсистеми `antigravity_cli` та `antigravity_ide` активні й готові до віддаленої оркестрації.

## 5. Перевірка Web IDE Code-Server (порт 8080)

Перевірка HTTP-відповіді:
```bash
curl -I -s http://localhost:8080/
```
**Результат:**
```http
HTTP/1.1 302 Found
Location: ./login
```

### Конфігурація та параметри доступу
- **Шлях до файлу конфігурації:** `/home/evabot/.config/code-server/config.yaml`
- **Права доступу:** `-rw-r--r-- 1 evabot evabot`
- **Вміст конфігурації:**
  ```yaml
  bind-addr: 0.0.0.0:8080
  auth: password
  password: antigravity-pass
  cert: false
  ```
- **Пароль для входу у веб-інтерфейс:** `antigravity-pass`

## 6. Інструкція: 0% споживання локальних ресурсів

Для запуску ресурсомістких завдань (компіляція коду, збирання проектів, виконання агентів і моделей) без навантаження на локальний комп'ютер (0% локального CPU і 0% RAM):

### Варіант 1: Прямий доступ через мережу Tailscale (Рекомендовано)
Локальний комп'ютер та сервер `evabot-agent-vm` вже об'єднані в мережу Tailscale:
- **Tailscale IP:** `100.66.98.4`
- **Web IDE у браузері:** [`http://100.66.98.4:8080/`](http://100.66.98.4:8080/)
- **Пароль:** `antigravity-pass`
- **Ендпоінт шлюзу:** [`http://100.66.98.4:9090/status`](http://100.66.98.4:9090/status)

*Переваги:* Не потрібні SSH-тунелі. Уся розробка, компіляція та обчислення виконуються на 8-ядерному Xeon із 32 ГБ DDR5 RAM, а локальний браузер відображає лише інтерфейс.

### Варіант 2: Захищений SSH-тунель через Google Cloud SDK
У разі підключення поза мережею Tailscale:
```bash
gcloud compute ssh evabot-agent-vm --zone europe-west3-a -- -L 8080:localhost:8080 -L 9090:localhost:9090 -N
```
Після чого відкрити у браузері:
- IDE: [`http://localhost:8080`](http://localhost:8080)
- Шлюз: [`http://localhost:9090/status`](http://localhost:9090/status)

### Варіант 3: Локальний VS Code через Remote-SSH
Додайте до локального файлу `~/.ssh/config`:
```ssh-config
Host evabot-agent-vm
    HostName 100.66.98.4
    User evabot
    IdentityFile ~/.ssh/google_compute_engine
```
Потім оберіть у VS Code **Remote-SSH: Connect to Host -> evabot-agent-vm**. Усі розширення, мовні сервери, термінали та компіляція на 100% виконуються на віддаленому сервері.
