# Голосовой модуль-плагин EvaBot Gemini Live — Спецификация и архитектура (RU)

## Общее описание
**Голосовой модуль EvaBot Gemini Live** — это изолированный, подключаемый (plug-and-play) модуль голосового взаимодействия на базе **Google Gemini Multimodal Live API** (`BidiGenerateContent` через WebSockets). Модуль обеспечивает живой, естественный диалог человека и ИИ с ультранизкой задержкой, поддержкой мгновенного перебивания речи (barge-in) и двумя ключевыми характерами:
- **Ева (Eva)**: Главный FrontEnd & UX Архитектор, выразительный, теплый, уверенный женский голос (`Aoede`).
- **Адам (Adam)**: Главный BackEnd & Cloud Архитектор, глубокий, авторитетный, аналитический мужской голос (`Fenrir`).

---

## Ключевые возможности

### 1. Изолированная плагинная архитектура
- Выделен в самостоятельные директории `src/plugins/voice/` (бэкенд-контроллер и конфигурации) и `src/web/voice/` (клиентский аудио-движок Web Audio API и интерфейс).
- Легко включается и выключается на лету (`POST /api/voice/toggle` или кнопка в UI `[ PLUGIN: ON/OFF ]`).
- При отключении плагина нулевая нагрузка на текстовый терминал и consilium.

### 2. Два персонажа и динамическое переключение голоса
- **Ева (♀ / Aoede)**: Специализация на фронтенде, дизайне интерфейсов, клиентской архитектуре и UX-эргономике.
- **Адам (♂ / Fenrir)**: Специализация на бэкенде, распределенных системах, PostgreSQL, кластерах и облачной безопасности.
- **Голосовое переключение**: Если пользователь обращается *"Ева / Eva"* или *"Адам / Adam"*, система распознает триггер и мгновенно переключает голос и характер.

### 3. Нативная многоязычность
- Поддержка **5 языков** с безупречным человеческим произношением:
  - Русский (RU)
  - Украинский (UK)
  - Английский (EN)
  - Польский (PL)
  - Румынский (RO)
- Модель автоматически отвечает на том языке, на котором к ней обратился пользователь.

### 4. Аудио-пайплайн сверхнизкой задержки
- **Захват микрофона**: 16 000 Гц, 16 бит PCM little-endian через Web Audio API и передача Base64-чанков в сокет.
- **Воспроизведение речи**: 24 000 Гц PCM через буферизированную очередь Web Audio API с компенсацией джиттера.
- **Мгновенный Barge-In (перебивание)**: воспроизведение мгновенно глушится, когда пользователь начинает говорить.
- **Кибер-осциллограф**: Canvas-визуализатор спектра и амплитуды в реальном времени.
