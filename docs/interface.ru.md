# EvaBot Engine – Мобильный Пользовательский Интерфейс

В этом документе описывается минималистичный мобильный интерфейс (в портретном режиме) для движка EvaBot, разработанный для управления большим пальцем одной руки. Интерфейс структурно идентичен для веб-браузеров и терминалов (Linux/Termux).

## 1. Главный Экран Чата (Первый Экран)

**Цель:** Максимальная простота, отображение только самых необходимых элементов.

```text
┌──────────────────────────────────────┐
│ ☰ EvaBot                     1200 🪙 │
├──────────────────────────────────────┤
│                                      │
│ Eva: Здравствуйте! Чем могу помочь?  │
│                                      │
│                                      │
│                                      │
│                                      │
│                                      │
│                                      │
│                                      │
│                                      │
├──────────────────────────────────────┤
│ ╭──────────────────────────────────╮ │
│ │ Введите сообщение...         [↑] │ │
│ ╰──────────────────────────────────╯ │
└──────────────────────────────────────┘
```

**Ключевые элементы:**
- **Шапка:** Гамбургер-меню (☰) слева для настроек, название по центру, текущий баланс токенов справа.
- **Область чата:** Чистый список сообщений с прокруткой без отвлекающих деталей.
- **Область ввода:** Поле ввода текста с закругленными рамками (или их эквивалент в TUI), расположенное внизу для удобного набора одной рукой. Кнопка отправки `[↑]`.

## 2. Меню Настроек (Второй Экран)

**Цель:** Постепенное раскрытие настроек, доступ через гамбургер-меню.

```text
┌──────────────────────────────────────┐
│ ← Назад                    Настройки │
├──────────────────────────────────────┤
│ Выбор Модели                         │
│ ◉ GPT-4o         $0.01 / 1K токенов  │
│ ◯ Claude 3.5 Sonnet  €0.015 / 1K ток │
│                                      │
│ Текущее Использование                │
│ - Стоимость Сессии: $0.05            │
│ - Доступные Токены: 12,500           │
│                                      │
│ Голосовые Опции                      │
│ [ ] Включить Голосовой Вывод         │
│                                      │
│ Внешний Вид                          │
│ [x] Темная Тема                      │
│                                      │
└──────────────────────────────────────┘
```

**Ключевые элементы:**
- **Шапка:** Кнопка возврата (`←`) слева для перехода в чат, заголовок справа.
- **Выбор Модели:** Список доступных моделей с их стоимостью строго в долларах США ($) или евро (€).
- **Текущее Использование:** Отображение стоимости сессии в реальном времени и оставшихся токенов.
- **Переключатели:** Легкодоступные флажки для настроек голоса и внешнего вида.
