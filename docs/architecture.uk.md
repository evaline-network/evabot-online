# Модульна архітектура та технічна специфікація EvaBot

**Версія:** 0.2.1  
**Статус:** Активна  
**Стандарти розрахунків:** Виключно долари США ($) та євро (€)  

---

## 1. Загальний огляд системи

EvaBot — модульний TypeScript-застосунок, підключений до повного каталогу Google Model Garden (моделі Gemini за підпискою Google AI Pro, відкриті моделі Gemma та Anthropic Claude через Vertex AI).

Архітектура забезпечує роботу у двох середовищах:
1. **Інтерактивний термінальний CLI (`npm run cli`):** Повнофункціональний REPL із живим потоковим виведенням, слеш-командами та переглядом каталогу моделей із цінами.
2. **Браузерний веб-інтерфейс (`https://evabot.online`):** Адаптивний темний інтерфейс із панеллю параметрів моделі (розцінки, ліміти токенів, індикатори безкоштовного/платного тарифу), Markdown, копіюванням коду та локальним збереженням API-ключа.

## 3. Віддалене керування Antigravity 2.0 на потужному сервері

Для перенесення 100% обчислювального навантаження на потужний сервер **`evabot-agent-vm`** (Франкфурт, `c3-standard-8`: 8 vCPU, 32 ГБ DDR5 RAM, 100 ГБ NVMe):

1. **Віддалене підключення через Remote SSH:**
   - Antigravity 2.0 підключається до сервера через SSH (`34.179.253.183` або Tailscale `100.66.98.4`).
   - Фоновий агент Antigravity розгортається безпосередньо на сервері `evabot-agent-vm`. Усі збірки, робота субагентів, індексація коду та виконання команд відбуваються на 8 ядрах процесора та 32 ГБ пам'яті віддаленого сервера. Навантаження на локальний комп'ютер становить 0%.
2. **Графічна веб-оболонка (Code-Server):**
   - На сервері вже працює служба `code-server` на порту 8080, що дає змогу працювати в повноцінному середовищі IDE напряму через браузер без витрат локальних ресурсів.
