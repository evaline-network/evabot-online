## 1. Автоматична автентифікація Google Cloud

EvaBot безпосередньо інтегрований із вашим обліковим записом Google Antigravity та Google Cloud (`evabot.online@gmail.com`).

- **Ручне введення API-ключа не потрібне:** Серверна частина взаємодіє зі службою метаданих віртуальної машини Google Compute Engine та обліковими даними Google Application Default Credentials (ADC).
- **Індикатор статусу:** У правому верхньому куті відображається статус `Google Auto-Auth (evabot.online@gmail.com)`.
- **Власний ключ:** За потреби протестувати інший API-ключ можна натиснути на плашку зі статусом та ввести його вручну в модальному вікні.
