# Спецификация фреймворка `un-ui` (Universal Text UI)
**Версия спецификации**: `1.1.0-RFC`  
**Назначение**: Построчный текстовый фреймворк для создания интерфейсов, идентично отображаемых в `.txt`/`.md` файлах, консольном выводе (`curl`), терминальных браузерах (`lynx`, `links2`, `w3m`) и графических веб-браузерах (Chrome, Firefox, Safari).

---

## 1. Концепция и фундаментальные аксиомы `un-ui`

1. **Аксиома текстового превосходства (Text-First Sovereignty)**:  
   Интерфейс обязан оставаться на 100% читаемым, информативным и эстетичным при открытии в обычном текстовом редакторе (`cat`, `nano`, `notepad`, `vim`, Obsidian) или при передаче по низкоскоростному каналу без поддержки стилей и JavaScript.

2. **Аксиома единого знаменателя (Single Source of Truth)**:  
   Один и тот же файл разметки (`.unui.txt` или `.unui.md`) без переписывания структуры компилируется в 4 целевых представления:
   - **CLI Stream**: чистый моноширинный вывод UTF-8 / ASCII для `curl`, `wget`, `httpie`.
   - **TUI HTML**: семантический HTML (`<pre>`, `<a>`, `<table>`) для `lynx`, `links2`, `w3m` с готовыми данными и без JavaScript.
   - **GUI Responsive Web**: 100vw/100vh веб-приложение со сменой тем (Dark/Light), шрифтом ровно 16px и live-гидратацией логов без внешнего скролла.
   - **Markdown Source**: нативный вид в GitHub / VS Code / Obsidian.

3. **Аксиома строгого запрета Emoji (Strict No-Emoji Standard)**:  
   **Категорически запрещено** использование любых Emoji-символов (таких как 🟢, 🟡, 🔴, ⚡, ★, ➜, ✔, ✖ и любых пиктограмм Unicode Emoji Presentation).  
   Разрешены **исключительно**:
   - Стандартные печатные символы ASCII: буквы, цифры, знаки препинания, скобки `[*]`, `[->]`, `[OK]`, `[WARN]`, `[ERR]`.
   - Псевдографика и геометрические символы Unicode: одинарные и двойные рамки (`┌─┐│└─┘`, `╔═╗║╚═╝`), маркеры (`●`, `■`, `□`, `▲`, `▼`, `█`).
   - ANSI Escape последовательности для подсветки текста в CLI-терминале.

4. **Аксиома монохрома и светофора (Traffic-Light & Monochrome)**:  
   Все структурные элементы (рамки, разделители, текст, лейблы, таблицы) строго монохромны (B&W / оттенки серого). Цвет разрешён **исключительно** как текстовая светофорная индикация состояния через CSS/ANSI:
   - Зелёный (`#00e676` / `#059669`) — `[OK]`, `LIVE`, `HEALTHY`, `ONLINE`, `200`, текущий узел.
   - Жёлтый/Янтарный (`#ffd600` / `#d97706`) — `[WARN]`, `[WRN]`, `308 Redirect`, `INGRESS`.
   - Красный (`#ff1744` / `#dc2626`) — `[ERR]`, `404/500`, `CRITICAL`, `OFFLINE`.
   *Запрещены*: любые синие, фиолетовые, градиентные или радужные заливки.

5. **Аксиома фиксированного шага сетки (Monospace Grid Alignment)**:  
   Каждый символ занимает ровно 1 знакоместо (1ch). Все колонки, таблицы и рамки выравниваются пробелами с точностью до символа.

6. **Аксиома экранного замка (Zero-Scroll 100vh)**:  
   Вся базовая навигация, метаданные, телеметрия и процессы укладываются в фиксированное число строк верхнего блока. Блок логов занимает оставшееся пространство экрана (`flex: 1`) с внутренним скроллом, исключая глобальную прокрутку окна.

## 3. Каталог элементов `un-ui` и правила синтаксиса

### 3.1. Заголовочная панель (Status Bar / Topbar)
- **Синтаксис**:
  ```text
  ┌── {TITLE} ── ● LIVE  UTC: {TIME} ── [{BUTTON_TEXT}] ──┐
  ```
- **Правила отображения**:
  - `curl / txt`: моноширинная строка в рамке символов Unicode (`┌─┐`).
  - `lynx / links2 / w3m`: верхняя строка с активными кнопками `(BUTTON)`.
  - `web GUI`: фиксированная шапка на всю ширину экрана (`width: 100vw; background: var(--surface)`), кнопка темы с хоткеем `T`, анимированный пульсирующий LED `●`.

### 3.2. Ключ-Значение метаданных (Key-Value Row)
- **Синтаксис**:
  ```text
  > {KEY:12} : {VALUE} [{BADGE}]
  ```
- **Правила**:
  - Ключ дополняется пробелами до фиксированной ширины (например, `12ch`).
  - Символ префикса `>` выводится приглушённым цветом (`--c-dim` / серый).
  - Значение выделяется жирным начертанием (`bold`), бейдж обрамляется в квадратные скобки `[...]`.

### 3.3. Разделители (Dividers)
- **Синтаксис**:
  ```text
  ────────────────────────────────────────────────────────────────────────────────
  ```
- **Правила**:
  - В чистом тексте — 80+ символов `─` (U+2500) или `-` (дефис).
  - В GUI — линия высотой 1px цвета темы `--border-dim`.

### 3.4. Навигация и кросс-ссылки (Cross-Links Navigation)
- **Синтаксис**:
  - Текущий узел: `[*] {DOMAIN:16} :: {ROLE} [ТЕКУЩИЙ УЗЕЛ]`
  - Внешний узел: `[->] https://{DOMAIN:14} :: {ROLE}`
- **Правила**:
  - Префикс `[*]` выделяется зелёным цветом и зелёным бейджем.
  - Префикс `[->]` монохромен, при наведении подчёркивает домен.
  - В текстовых браузерах превращается в стандартные ссылки с переходами по `Enter`.

### 3.5. Индикаторы нагрузки и полосы прогресса (Gauge / Progress Bar)
- **Синтаксис**:
  ```text
  CPU: 62% [■■■■■■□□□□]
  RAM: 8.2 / 31.3 GB (26%) [■■■□□□□□□□]
  ```
- **Правила**:
  - Полоса состоит ровно из 10 сегментов в скобках: `■` (U+25A0, заполненный) и `□` (U+25A1, пустой).
  - Процент округляется: каждые 10% заполняют 1 квадратик `■`.
  - От 0% до 79% — цвет индикатора зелёный.
  - От 80% до 89% — янтарный/жёлтый.
  - От 90% до 100% — красный.

### 3.6. Таблица процессов (Process Watcher Table)
- **Синтаксис**:
  ```text
  PID     УЗЕЛ             ПРОЦЕСС / СЛУЖБА             CPU    ОЗУ      СТАТУС
  198311  evabot-agent-vm  evabot-brain (Node.js)       0.1%   70 MB    [HEALTHY]
  171143  evabot-agent-vm  omniroute (LiteLLM)          0.0%   317 MB   [HEALTHY]
  169534  cluster-mesh     tailscaled (WireGuard)       0.1%   78 MB    [OPERATIONAL]
  32403   evaline-micro-vm caddy (Edge)                 0.4%   54 MB    [HEALTHY]
  ```
- **Правила**:
  - Фиксированные слоты колонок: `PID (7ch)`, `УЗЕЛ (16ch)`, `СЛУЖБА (28ch)`, `CPU (6ch)`, `ОЗУ (8ch)`, `СТАТУС (14ch)`.
  - В HTML оборачивается в `<table>` или `<pre>`, гарантируя 100% табличный вид в Lynx и W3M.

### 3.7. Потоковый лог событий (Log & Event Stream)
- **Синтаксис**:
  ```text
  [{HH:MM:SS}] [{STATUS_BADGE}] {HTTP_CODE} {METHOD} {HOST} {URI} ({PROTO} {RTT}ms) ip:{CLIENT_IP}
  ```
  Пример:
  ```text
  [08:36:51] [OK]  200 GET evabot.online   /api/health (HTTP/2.0 148ms) ip:34.159.202.82
  [08:36:50] [WRN] 308 GET evaline.website /wp-admin   (HTTP/1.1 12ms)  ip:104.23.223.32
  [08:36:49] [ERR] 404 GET evaline.online  /unknown    (HTTP/2.0 5ms)   ip:46.211.44.120
  ```
- **Правила**:
  - Каждая строка лога имеет фиксированную высоту (`line-height: 22px`).
  - Обязательно `flex-shrink: 0`, чтобы браузерный flexbox не сжимал строки при заполнении экрана.
  - В браузере блок занимает всё свободное пространство до конца экрана (`flex: 1; overflow-y: auto;`).

### 3.8. Терминальный курсор и строка ввода (Prompt Footer)
- **Синтаксис**:
  ```text
  evabot@evaline-mesh:~$ █
  ```
- **Правила**:
  - Символ блока `█` (U+2588) непрерывно мигает с интервалом в 1 секунду (`cur-blink`).
  - В терминале (`curl`, `lynx`) остаётся статичным символом `█`.

## 5. Роли узлов кластера

1. **`evabot.online`** — `[NEURAL CORE]`: Вычислительное ядро ИИ, оркестрация мультиагентных консилиумов.
2. **`evaline.network`** — `[EDGE MESH]`: Пограничный шлюз, транс-региональная маршрутизация WireGuard.
3. **`evaline.online`** — `[SECURITY & IAM]`: Периметр безопасности, OOM-защита, фильтрация атак.
4. **`evaline.website`** — `[CHRONICLE]`: Мастер-хроника релизов, архитектурная документация и ворклог.
