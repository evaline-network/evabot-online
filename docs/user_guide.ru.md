## 1. Автоматическая аутентификация Google Cloud

EvaBot напрямую интегрирован с вашей учетной записью Google Antigravity и Google Cloud (`evabot.online@gmail.com`).

- **Ручной ввод API-ключа не требуется:** Бэкенд автоматически взаимодействует со службой метаданных виртуальной машины Google Compute Engine и учетными данными Google Application Default Credentials (ADC).
- **Индикатор статуса:** В правом верхнем углу интерфейса отображается статус `Google Auto-Auth (evabot.online@gmail.com)`.
- **Пользовательский ключ:** При необходимости протестировать сторонний API-ключ можно кликнуть на плашку со статусом и ввести его вручную в модальном окне.
