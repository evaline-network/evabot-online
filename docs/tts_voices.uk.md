# Найкращі голоси Google Cloud TTS

У цьому документі перелічені найбільш реалістичні та високоякісні голоси синтезу мовлення (TTS) від Google Cloud для вибраних мов. Преміум-рівні включають **Studio**, **Journey** та **Neural2**, які забезпечують виняткову природність і правильну вимову. Там, де вони ще не підтримуються, **WaveNet** вказано як альтернативу найвищої якості.

## Ціни (за 1 мільйон символів)
- **Studio:** $160.00
- **Neural2:** $16.00
- **WaveNet:** $16.00
- **Standard:** $4.00

*(Примітка: Ціни вказані у USD та базуються на стандартних тарифах Google Cloud Text-to-Speech.)*

## Рекомендовані голоси за мовами

### Англійська (EN)
Для англійської мови доступний найширший вибір ультра-реалістичних голосів.
- **Жіночі:** `en-US-Studio-O`, `en-US-Journey-F`, `en-US-Neural2-C`
- **Чоловічі:** `en-US-Studio-M`, `en-US-Journey-D`, `en-US-Neural2-D`

### Російська (RU)
Для російської мови рекомендуються такі високоякісні моделі:
- **Жіночі:** `ru-RU-Wavenet-A`, `ru-RU-Wavenet-C` (або Neural2, якщо доступно у вашому регіоні)
- **Чоловічі:** `ru-RU-Wavenet-B`, `ru-RU-Wavenet-D`

### Українська (UK)
Для української мови моделі WaveNet забезпечують найбільш природне звучання:
- **Жіночі:** `uk-UA-Wavenet-A`
- **Чоловічі:** `uk-UA-Wavenet-M` (або стандартні чоловічі голоси WaveNet)

### Польська (PL)
Польська мова підтримує просунуті нейронні моделі для максимально природного мовлення:
- **Жіночі:** `pl-PL-Neural2-A`, `pl-PL-Wavenet-A`
- **Чоловічі:** `pl-PL-Neural2-B`, `pl-PL-Wavenet-B`

### Румунська (RO)
Для румунської мови WaveNet пропонує найкращу доступну реалістичну якість:
- **Жіночі:** `ro-RO-Wavenet-A`
- **Чоловічі:** `ro-RO-Wavenet-B`
