# EvaBot Engine – Мобільний Користувацький Інтерфейс

У цьому документі описується мінімалістичний мобільний інтерфейс (у портретному режимі) для рушія EvaBot, розроблений для керування великим пальцем однієї руки. Інтерфейс структурно ідентичний для веб-браузерів та терміналів (Linux/Termux).

## 1. Головний Екран Чату (Перший Екран)

**Мета:** Максимальна простота, відображення лише найнеобхідніших елементів.

```text
┌──────────────────────────────────────┐
│ ☰ EvaBot                     1200 🪙 │
├──────────────────────────────────────┤
│                                      │
│ Eva: Вітаю! Чим можу допомогти?      │
│                                      │
│                                      │
│                                      │
│                                      │
│                                      │
│                                      │
│                                      │
│                                      │
├──────────────────────────────────────┤
│ ╭──────────────────────────────────╮ │
│ │ Введіть повідомлення...      [↑] │ │
│ ╰──────────────────────────────────╯ │
└──────────────────────────────────────┘
```

**Ключові елементи:**
- **Шапка:** Гамбургер-меню (☰) зліва для налаштувань, назва по центру, поточний баланс токенів справа.
- **Область чату:** Чистий список повідомлень з прокруткою без відволікаючих деталей.
- **Область вводу:** Поле вводу тексту із заокругленими рамками (або їх еквівалент в TUI), розташоване внизу для зручного набору однією рукою. Кнопка відправлення `[↑]`.

## 2. Меню Налаштувань (Другий Екран)

**Мета:** Поступове розкриття налаштувань, доступ через гамбургер-меню.

```text
┌──────────────────────────────────────┐
│ ← Назад                  Налаштування│
├──────────────────────────────────────┤
│ Вибір Моделі                         │
│ ◉ GPT-4o         $0.01 / 1K токенів  │
│ ◯ Claude 3.5 Sonnet  €0.015 / 1K ток │
│                                      │
│ Поточне Використання                 │
│ - Вартість Сесії: $0.05              │
│ - Доступні Токени: 12,500            │
│                                      │
│ Голосові Опції                       │
│ [ ] Увімкнути Голосовий Вивід        │
│                                      │
│ Зовнішній Вигляд                     │
│ [x] Темна Тема                       │
│                                      │
└──────────────────────────────────────┘
```

**Ключові елементи:**
- **Шапка:** Кнопка повернення (`←`) зліва для переходу в чат, заголовок справа.
- **Вибір Моделі:** Список доступних моделей з їхньою вартістю строго у доларах США ($) або євро (€).
- **Поточне Використання:** Відображення вартості сесії в реальному часі та залишкових токенів.
- **Перемикачі:** Легкодоступні прапорці для налаштувань голосу та зовнішнього вигляду.
