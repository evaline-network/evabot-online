# Модульная архитектура и техническая спецификация EvaBot

**Версия:** 0.2.1  
**Статус:** Активна  
**Стандарты расчетов:** Исключительно доллары США ($) и евро (€)  

---

## 1. Обзор системы

EvaBot — модульное TypeScript-приложение, подключенное к полному каталогу Google Model Garden (модели Gemini по подписке Google AI Pro, открытые модели Gemma и Anthropic Claude через Vertex AI).

Архитектура обеспечивает работу в двух средах:
1. **Интерактивный терминальный CLI (`npm run cli`):** Полноценный REPL с живым потоковым выводом, слэш-командами и выводом каталога моделей с ценами.
2. **Браузерный веб-интерфейс (`https://evabot.online`):** Адаптивный темный интерфейс с панелью параметров модели (расценки, лимиты токенов, индикаторы бесплатного/платного тарифа), Markdown, копированием кода и локальным хранением API-ключа.

## 3. Удаленное управление Antigravity 2.0 на мощном сервере

Для переноса 100% вычислительной нагрузки на мощный сервер **`evabot-agent-vm`** (Франкфурт, `c3-standard-8`: 8 vCPU, 32 ГБ DDR5 RAM, 100 ГБ NVMe):

1. **Удаленное подключение через Remote SSH:**
   - Antigravity 2.0 подключается к серверу по SSH (`34.179.253.183` или Tailscale `100.66.98.4`).
   - Фоновый агент Antigravity разворачивается непосредственно на сервере `evabot-agent-vm`. Все сборки, запуск субагентов, индексация кода и исполнение команд происходят на 8 ядрах процессора и 32 ГБ памяти удаленного сервера. Нагрузка на локальный компьютер составляет 0%.
2. **Графическая веб-оболочка (Code-Server):**
   - На сервере уже активен `code-server` на порту 8080, что позволяет работать в полноценной среде IDE прямо через браузер без расхода ресурсов локального ПК.
