# Лучшие голоса Google Cloud TTS

В этом документе перечислены самые реалистичные и высококачественные голоса синтеза речи (TTS) от Google Cloud для выбранных языков. Премиум-уровни включают **Studio**, **Journey** и **Neural2**, которые обеспечивают исключительную естественность и правильное произношение. Там, где они еще не поддерживаются, **WaveNet** указан как альтернатива высшего качества.

## Цены (за 1 миллион символов)
- **Studio:** $160.00
- **Neural2:** $16.00
- **WaveNet:** $16.00
- **Standard:** $4.00

*(Примечание: Цены указаны в USD и основаны на стандартных тарифах Google Cloud Text-to-Speech.)*

## Рекомендуемые голоса по языкам

### Английский (EN)
Для английского языка доступен самый широкий выбор ультра-реалистичных голосов.
- **Женские:** `en-US-Studio-O`, `en-US-Journey-F`, `en-US-Neural2-C`
- **Мужские:** `en-US-Studio-M`, `en-US-Journey-D`, `en-US-Neural2-D`

### Русский (RU)
Для русского языка рекомендуются следующие высококачественные модели:
- **Женские:** `ru-RU-Wavenet-A`, `ru-RU-Wavenet-C` (или Neural2, если доступно в вашем регионе)
- **Мужские:** `ru-RU-Wavenet-B`, `ru-RU-Wavenet-D`

### Украинский (UK)
Для украинского языка модели WaveNet обеспечивают наиболее естественное звучание:
- **Женские:** `uk-UA-Wavenet-A`
- **Мужские:** `uk-UA-Wavenet-M` (или стандартные мужские голоса WaveNet)

### Польский (PL)
Польский язык поддерживает продвинутые нейронные модели для максимально естественной речи:
- **Женские:** `pl-PL-Neural2-A`, `pl-PL-Wavenet-A`
- **Мужские:** `pl-PL-Neural2-B`, `pl-PL-Wavenet-B`

### Румынский (RO)
Для румынского языка WaveNet предлагает лучшее доступное реалистичное качество:
- **Женские:** `ro-RO-Wavenet-A`
- **Мужские:** `ro-RO-Wavenet-B`
